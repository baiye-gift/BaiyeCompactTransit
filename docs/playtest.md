# Unity 分项验收（0.1.5）

使用沙盒或存档副本；确认版本及已启用模组。用户已确认 0.1.2“整体运行可以”，并确认 0.1.5 的建管空引用已经修复、当前运行没有问题。以下完整矩阵仍未逐项记录，不可根据这次反馈或托管测试全部勾选通过。

1. 模组加载无红色报错；基地菜单出现紧凑站，研究解锁正确，建造预览确实为 1×2，普通入口仍可建造。
2. 在空中完成建造 1×2 站体，脚下不铺地板或渡口，确认完成后可站立且不再报无地基；施工前需能从侧面接近。上下直接接普通竖直管道，确认显示和传输均连续。沿直管建设两站，分别安排复制人去上层和下层工作。
3. 用普通建造、沙盒即时建造分别将管道拖线穿过已完成站体上格和下格，松开鼠标不得报错；也测试以站体为拖线起点/终点、单击站体和横向经过。本站不得被替换为普通管道，侧口不能接管。之后确认本站动画、上下行和原版普通管道升级/建造正常。
4. 三层站上下贯通：去远层时经过中间站，去中层时正常出舱；中站双向上车均可达目的地。在中站两侧去掉地板时，只能经过而不能下车。恢复任一侧平台通道后可正常下车。侧管不得接入步行开口；原版其他管道/渡口仍能正常建造。
5. 检查管壁、磁极接环和底边平台是否形成一体轮廓，站内不得看成完整封闭管道背景加设备贴片；确认外部上下管道宽度、接缝和遮挡。检查接环电量表、平台蜡表、短磁极亮起、上/下行侧壁流光与右屏箭头、中性发射光效及复位渐隐。正常游戏缩放与放大均观察，光效不遮住复制人和装备。分别测试左进左出、左进右出、右进左出和右进右出；堵住一侧后另一侧仍可用；普通步行能穿过空闲站体。确认脚部与踏板位置、人物与一体管壁的遮挡正确，菜单图和中英文侧栏正常，充满停止耗电。
6. 首次 0 kJ 不发射；充电至 10 kJ 后可用；单人发射扣 10 kJ。多人竞争时不超额预约，取消任务后正确释放。底接站也满足上述规则。
7. 禁用/红信号禁止新乘客进入，已经经过及准备离开的乘客正常移动；断电后仍按原版缓存电量规则运行，堵住出口不导致落进地板。
8. 删除、旋转、修复顶部/底部管道和渡口，观察约 200 ms 后连接状态更新及路线重算；分别先建管后建站、先建站后建管并保存读档，确认上下相邻管段没有端帽或横向断缝，不能跨过缺口。
9. 开启加速蜡按钮，配送和消耗仍由原版处理；上行与下行启动动画均正常。
10. 新建悬空站保存/读档，检查薄平台支撑、连接、电量、蜡、路线和侧栏；升级含 0.1.1—0.1.4 站体的存档，确认原站体直接显示新外观及仪表，不需重建。0.1.1 升级还需检查新增支撑，拆掉旧脚下地板/渡口后重新直连下管道。原版入口仍正常。
11. 空闲、等待预约、发射中和旅客经过时分别拆站，检查无崩溃、幽灵入口或卡住旅客；拆后重建，退出到主菜单再读档。
12. 单独启用本模组通过后，逐个恢复常用模组，特别是修改运载管道/导航/入口的模组，重测上下行和原版入口。

失败时保存游戏日志、版本、模组列表和最小地图，记录具体站点布局、复制人的任务与预期/实际行为。
