# 紧凑型双向运载站 / Baiye Compact Transit

0.1.5 圆润接环站台开发测试版，面向《缺氧》U59 / 744825 及以上版本。使用当前本机 744825 程序集编译；未来版本兼容性需要重新验证。独立于聚变电力模组，没有第三方模组依赖。

源码仓库：[baiye-gift/BaiyeCompactTransit](https://github.com/baiye-gift/BaiyeCompactTransit)。项目内 `CHANGELOG.md` 保存开发记录，独立克隆后可以直接按下文构建。

## 功能

- 新增宽 1 格、高 2 格的悬空运载站，同一站点可进入和离开；底边自带一格宽薄平台，提供原版站立支撑，不另占地板格。
- 上接、下接、上下贯通；中间站可以经过，也可以作为目的地出口。
- 复用原版运载管道寻路、目的地选择、速度、储电、充能预约和加速蜡。
- 960 W 充电，40 kJ 储电，每次发射 10 kJ；充满后停止耗电。建筑材料与原版入口一致：800 kg 精炼金属。
- 圆润接环、短磁极、非对称方向屏和底边薄平台采用一张整体外壳，不在完整封闭圆管上叠加设备贴片；站内中央真实透明，左右保持开放。启动时磁极亮起，两侧短流光按已选原版路线向上或向下移动，对应方向箭头亮起，中央不画圆环；接环电量表和平台蜡表保留原生计量逻辑。
- 修复原版拖建管道经过已完成站体时的空引用：保留原版建管接口，并由本站继续控制外观和管网清理。
- 原版启停按钮与自动化红信号控制发射，允许旅客离开和经过。

研究解锁：运载管道；建造菜单：基地。原版入口和管道保留。新建筑 ID 为 `BaiyeCompactTransitStation`，不会自动替换已有入口。

## 安装

退出游戏，将 `BaiyeCompactTransit-0.1.5.zip` 解压至缺氧用户目录的 `mods/local/`，得到 `mods/local/BaiyeCompactTransit/mod.yaml`。默认用户目录一般位于“文档/Klei/OxygenNotIncluded”。在模组列表启用并按游戏提示重启。已有 0.1.0/0.1.1/0.1.2/0.1.3/0.1.4 时备份同名模组目录再覆盖；建筑 ID、储电和蜡的存储规则保持一致。

首次建议在存档副本或沙盒地图验收。用户已实机反馈 0.1.2“整体运行可以”，并确认 0.1.5 的拖建空引用已修复、当前运行没有问题；完整分项验收矩阵尚未逐项记录。自动检查的范围见下文和 [分项验收](docs/playtest.md)。

## 楼层布置

**一条直管道，每层挂一个站台。** 站体逻辑占用同一列的两格，接环外观略宽，踏板表面与左右地板齐平，薄前脸向下少量延伸，可悬空建造，站内自动形成原版管道连接。不需要在站体里额外铺管，也不需要在脚下另铺地板或渡口。施工时复制人仍需能接近建造位置，例如从旁边走廊或临时梯子施工。

底边的平台提供真正的站立支撑。复制人从可达的左侧或右侧走到站内底格，再进入竖直管道；下车时回到平台，然后按任务目的地步行离开。左右是人行开口，不接受横向管道。两侧都可达时可双侧进出；一侧被墙堵住时只能使用另一侧；两侧均没有可站立的通道时，禁止下车，保留上下贯通。平台不形成密封地砖，气液仍沿用所在空间的模拟。

发布包的 `CONNECTIONS.png` 给出清晰的逻辑示意图；项目源图为 `docs/connection-layout.png`。

```text
              竖直管道
                 │
              站体上格
左通道  ⇄     站体下格     ⇄  右通道
地板 ───────【自带平台】─────── 地板
                 │
              竖直管道
```

平台下方的同一列直接接普通运载管道；站台左右的地板不延伸到管道列，因此本站无需额外渡口。其他位置的实心楼板仍需原版渡口穿越。仅上接、仅下接和上下贯通均可用；复制人仍由原版寻路按工作目的地自动决定在哪一站下车，不需要手选楼层。

建议沿同一列建竖直管道，在停靠层留出两格站体位置，再把走廊接到平台左右。楼层间仍需要连续管道；原版建设、环境和复制人能力要求继续生效。原有 0.1.1 站体升级后无需拆除即可获得平台支撑；是否拆掉旧脚下地板/渡口取决于你的布置，升级存档仍待实机验收。

## 构建与验证

需要 .NET 8 SDK 和本机游戏 Managed 程序集；代码面向 Unity 使用的 `netstandard2.1`。默认游戏路径在 `.csproj` 和工具参数中，可用 `-p:GameManaged=...` 或脚本 `-GameManaged` 覆盖。

```powershell
dotnet build CompactTransit.csproj -c Release
dotnet build tests/Native -c Release
dotnet run --project tests/Native -c Release --no-build -- "游戏/OxygenNotIncluded_Data/Managed"
python tools/verify-assets.py
./tools/build-package.ps1
```

发布包使用已导出的 KAnim，普通代码构建不需要动画编译器。修改美术后运行 `tools/build-anims.ps1 -Kanimal "kanimal-cli.exe" -Python "python"`；该工具保留生成的原始外壳图，只执行精灵导入、机械部件绘制和动画打包。动画工具需要 Windows PowerShell 运行环境支持 System.Drawing，推荐 PowerShell 7。
